## 🚀 Project Overview

**ClassifiedHub** is a comprehensive, modern classified advertisements platform designed to revolutionize how people buy, sell, and trade items online. Built with the latest web technologies, it offers a seamless, secure, and feature-rich experience for both buyers and sellers.

### 🎯 Vision Statement
To create the most user-friendly, secure, and efficient classified ads platform that connects buyers and sellers through innovative technology and exceptional user experience.

## 🛠️ Technology Stack

### **Frontend**
- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn/ui
- **State Management**: React Hooks & Context
- **Animations**: Framer Motion

### **Backend & Database**
- **Runtime**: Node.js
- **API**: RESTful APIs with Next.js API Routes
- **Database**: PostgreSQL (Production Ready)
- **ORM**: Prisma
- **Authentication**: NextAuth.js
- **File Storage**: Vercel Blob Storage

### **Real-time Features**
- **WebSockets**: Socket.io for live chat
- **Push Notifications**: Web Push API
- **Live Updates**: Server-Sent Events

### **Payment Integration**
- **Gateway**: PayHere (Sri Lankan market)
- **Security**: PCI DSS compliant
- **Methods**: Cards, Mobile Banking, Digital Wallets

## 🚀 Getting Started

### **Prerequisites**
- Node.js 18+ 
- npm or yarn
- PostgreSQL database

### **Installation**
\`\`\`bash
# Clone the repository
git clone https://github.com/yourusername/classifiedhub.git

# Navigate to project directory
cd classifiedhub

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local

# Run database migrations
npx prisma migrate dev

# Start development server
npm run dev
\`\`\`

### **Environment Variables**
\`\`\`env
DATABASE_URL="postgresql://..."
NEXTAUTH_SECRET="your-secret-key"
NEXTAUTH_URL="http://localhost:3000"
PAYHERE_MERCHANT_ID="your-merchant-id"
PAYHERE_SECRET="your-payhere-secret"
\`\`\`
